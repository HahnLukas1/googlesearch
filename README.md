# Google Search – CS50 Project 0

Školní projekt: statické rozhraní podobné Google Search podle zadání [CS50 Search](https://cs50.harvard.edu/web/projects/0/search/).

## Stránky

- `index.html` – běžné vyhledávání Google + I'm Feeling Lucky
- `images.html` – vyhledávání obrázků přes parametr `udm=2`
- `advanced.html` – pokročilé vyhledávání (`as_q`, `as_epq`, `as_oq`, `as_eq`)
- `style.css` – společný vzhled všech tří stránek

## Jak spustit

Otevři `index.html` v prohlížeči, případně spusť rozšíření Live Server ve Visual Studio Code.

## Zveřejnění na GitHub Pages

V repozitáři otevři **Settings → Pages → Build and deployment**, vyber **Deploy from a branch** a nastav **main** a **/(root)**. Stránka bude dostupná na `https://TVUJ-USERNAME.github.io/googlesearch/`.

Poznámka: Google může podle země a svých aktualizací měnit chování vyhledávání obrázků a tlačítka I'm Feeling Lucky. Navigace na samotný Google funguje bez JavaScriptu pomocí HTML formulářů.
